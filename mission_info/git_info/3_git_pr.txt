1. git pull request
    1-1. 한 브랜치에서 작업한 변경 사항을 다른 브랜치에 반영해 달라고 요청하는 것입니다.
    1-2. pr은 git 자체의 명령어나 객체가 아니라, github 같은 협업 플랫폼에서 제공하는 기능입니다.
    1-3. git pr이라는 표준 명령어는 없습니다.


2. branch
    2-1. 특정 커밋을 가리키는, 이동 가능한 이름입니다.
    2-2. Git은 새로운 커밋을 생성하면 현재 브랜치가 새 커밋을 가리키도록 갱신합니다.
    2-3. 예시
        => Commit A → Commit B → Commit C
                                    ↑
                                    main
        => git switch -c feature/login 
        => feature/login, main 브랜치 모두 Commit C를 가리킵니다.
        => main이 Commit D로 작업을 하고 feature/login도 자신의 작업을 합니다.
        => 이 떄 로그인 기능을 main에 반영하고 싶다면?
        => pr를 생성합니다.


3. PR을 생성할 때는 두 브랜치를 선택합니다.
    3-1. Base Branch: 변경 사항을 반영할 대상 브랜치
    3-2. Compare/Head Branch: 변경 사항을 가져올 작업 브랜치
        => Base Branch는 main,  Compare/Head Branch는 feature/login
    3-3. git diff main...feature/login
        => 세 개의 점 ...은 이 명령어에서 두 브랜치의 공통 조상을 기준으로 비교하도록 하는 의미입니다.
        => main에서 독립적으로 추가된 변경 사항보다는 
            feature/login에서 수행한 작업을 중심으로 검토할 수 있습니다.


4. PR은 Github 저장소에서 Pull request 탭에서 New Pull Request를 선택합니다.
    => PR 제목과 설명을 작성하고 생성합니다.
    => base: main ← compare: feature/login
