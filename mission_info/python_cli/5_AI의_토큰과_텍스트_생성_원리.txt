1. 토큰
    1-1. AI는 입력한 문자열을 그대로 처리하는 것이 아니라, 토큰이라는 작은 단위로 분리해서 처리합니다.
        => 토큰이 반드시 단어 하나를 의미하는 것은 아닙니다.
        => 즉, 토큰은 글자나 단어와 정확히 일치하는 개념이 아니라 AI가 텍스트를 처리하기 위해 사용하는 기본 단위입니다.


2. 토크나이저 (tokenizer)
    2-1. 문자열을 토큰으로 분리하고, 각 토큰을 정수 ID로 변환하는 도구입니다.
    2-2. 컴퓨터에서 AI 모델은 문자열 자체가 아닌 수치 데이터를 기반으로 연산하기 때문입니다.
    2-3. 예시
        text = "I love programming."
        tokens = [40, 3021, 15840, 13]
        => 이러한 변환 과정을 토큰화라고 합니다.
    2-4. AI 모델 내부에서는 이 정수 ID를 다시 여러 실수로 이루어진 벡터로 변환하는데, 이와 관련된 개념이 임베딩입니다.


3. AI의 텍스트 생성 원리
    3-1. 지금까지 주어진 토큰들을 바탕으로 다음에 등장할 토큰을 예측하는 것입니다.
    3-2. 예시
        => 대한민국의 수도는 -> 사용자 입력
        => AI 모델은 앞에 입력된 토큰들의 관계와 학습된 패턴을 바탕으로 다음 토큰에 대한 확률 분포를 계산합니다.
        => 이러한 생성 방식을 자기회귀(Autoregressive) 방식이라고 합니다.


4. 입력 토큰과 출력 토큰
    4-1. input token : AI 모델에 입력하는 토큰
    4-2. output token : AI 모델이 생성하는 토큰
    4-3. 대부분의 유료 텍스트 생성 API에서는 이러한 토큰 사용량을 기반으로 비용을 계산합니다.


5. 컨텍스트 윈도우
    5-1. AI 모델이 한 번의 처리 과정에서 다룰 수 있는 토큰의 범위를 의미합니다.
        => AI가 답변을 생성할 때 참고할 수 있는 문맥의 최대 크기입니다.
    5-2. 이 개념이 중요한 이유는 git diff의 길이가 항상 일정하지 않기 때문입니다.
        => 파일 하나를 수정하면 입력 토큰이 적겠지만, 수십 개의 파일을 수정하면 입력 토큰이 매우 많아질 수 있습니다.
        => 프로그램을 설계할 때 입력 길이 제한이나 지나치게 큰 diff에 대한 예외 처리도 고려해야 합니다.


6. Temperature
    6-1. AI의 다음 토큰 선택에 사용되는 확률 분포를 조절하는 매개변수입니다.
    6-2. Temperature가 낮으면 확률이 높은 토큰에 선택 가능성이 집중되고,
        높으면 상대적으로 확률이 낮은 토큰도 선택될 가능성이 커집니다.
