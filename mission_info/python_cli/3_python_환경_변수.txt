1. 환경 변수
    1-1. 프로세스의 실행 환경에 존재하는 이름과 값의 쌍입니다.
    1-2. 환경 변수의 이름과 값은 문자열로 관리됩니다.
    1-3. 예시
        환경변수                이름	                    값 예시	역할
        PATH	            /usr/bin:/usr/local/bin	    실행 파일을 찾을 경로
        HOME	            /Users/user	                사용자 홈 디렉터리
        LANG	            ko_KR.UTF-8	                언어 및 지역 설정
        OPENAI_API_KEY	    sk-...	                    OpenAI API 인증 키
        MY_NAME	            hong	                    사용자가 임의로 정의한 값


2. 환경 변수 위치 공간
    2-1. 모든 프로세스는 자신의 환경변수 집합을 가지고 있습니다.
    2-2. 일반적으로 자식 프로세스가 생성될 때 부모 프로세스의 환경변수를 상속받습니다.
    2-3. 자식 프로세스에서 환경 변수 변경 -> 부모 프로세스나 다른 프로세스가 자동으로 변경되지 않습니다.


3. 환경 변수 파악하기
    3-1. printenv
        => 현재 셸의 환경 변수 전체를 확인하는 명령어입니다.
    3-2. 특정 환경 변수 확인
        => printenv 환경_변수_key
    3-3. 환경 변수 설정
        => export MY_NAME="hong" -> key="value"는 띄어쓰면 안됩니다.
        => MY_NAME은 key, "hong"은 value입니다.
    3-4. 환경 변수 출력
        => echo $key_name
        => echo $MY_NAME -> hong


4. python os 모듈
    => import os
    => os 모듈을 이용하면 파일과 디렉터리 관리, 현재 작업 경로 확인, 환경변수 접근 등의 작업을 할 수 있습니다.
    => os.getenv()를 통해 환경 변수를 읽을 수 있습니다.


5. os.getenv()
    5-1. os.getenv("환경변수 이름") / os.getenv("MY_NAME")
    5-2. 반환값은 문자열이고 타입은 str입니다.
    5-3. 만약 환경 변수가 존재하지 않는다면 반환값은 None, 타입은 NoneType
    5-4. os.getenv("my_nnn", "guest")
        => 만약 첫 번쨰 인자에 해당되는 환경 변수가 없다면 두 번쨰 인자를 기본값으로 사용합니다.


6. os.environ() or os.environ.get()
    6-1. os.environ["MY_NAME"] / os.environ.get("MY_NAME")
    6-2. 환경 변수가 존재한다면 문자열, 타입은 str
    6-3. 존재하지 않는다면 []은 KeyError/ ()은 None을 반환합니다.
    6-4. 환경 변수를 설정하거나 변경할 떄는 os.environ를 사용합니다.
        => os.environ["MY_NAME"] = "kim"


7. API Key를 환경 변수로 관리하는 이유
    7-1. AI API를 사용하려면 일반적으로 API Key가 필요합니다.
    7-2. GitHub에 올린다면 API Key도 함께 공개될 수 있습니다.
    7-3. export OPENAI_API_KEY="발급받은_API_KEY" / api_key = os.getenv("OPENAI_API_KEY")
        => 실제 키는 소스 코드와 분리되어 있습니다.


8. 환경 변수의 수명
    8-1. 터미널을 종료하고 새로운 터미널을 열면 직접 export로 설정한 환경 변수는 사라집니다.
        => 해당 셸 프로세스가 종료되었기 때문입니다.
    8-2. 매번 설정하기 싫다면 macOS의 zsh 환경에서는 ~/.zshrc 같은 셸 설정 파일에 export 명령을 작성하는 방법도 존재합니다.
