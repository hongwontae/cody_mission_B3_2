1. 프로그램 설명
    1-1. 수정 전 -> 수정
        => 일반적인 git 작업에서는 개발자가 직접 커밋 메시지를 작성합니다.
    1-2. 만들 프로그램에서는 개발자가 변경 내용을 직접 설명하지 않아도 됩니다.
        => python main.py commit -> 명령어 입력
    1-3. commit 메시지를 AI가 대신 작성해 주는 프로그램입니다.
        => AI가 실제로 Git 커밋을 생성하는 게 아니라 커밋 메시지라는 텍스트만 생성한다는 것입니다.
        => 사용자가 결과를 확인한 뒤 직접 git add, git commit을 실행합니다.
    1-4. pr도 마찬가지입니다.
        => python main.py pr
        => PR Title:
            fix: 나이 입력 검증 추가

            PR Body: ...


2. 프로그램 흐름
    2-1. python main.py commit
    2-2. Git에서 수정 내역 수집
        => git status, git diff
    2-3. AI에게 질문 전달
        => "다음 Git 변경 내용을 분석해서 커밋 메시지를 작성해 줘."
    2-4. AI 생성 결과 출력
        => fix: 음수 나이 입력 검증 기능 추가
