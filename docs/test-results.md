# 테스트 결과 보고서

## 1. 테스트 목적

AI GitGen 프로그램의 커밋 메시지 생성, PR 설명 생성, Git 변경 사항 분석, AI API 연동 및 예외 처리 기능을 검증한다.

## 2. 테스트 환경

- 운영체제: macOS
- 개발 환경: Visual Studio Code
- Python: 3.12
- AI API: Google Gemini API
- AI 모델: gemini-3.1-flash-lite
- HTTP 통신 라이브러리: requests
- 버전 관리 시스템: Git
- Python 가상환경: venv

- 실제 결과: feat: student.cpp의 age 변수 값을 10에서 20으로 수정

메시지 생성에는 성공하였지만 단순 변수 초기값 변경을 새로운 기능으로 판단하는 문제가 발생하였다. 이후 프롬프트 비교 실험을 통해 개선 방향을 확인하였다.

## 5. 테스트 결과 및 개선 사항

AI API 연동, Git diff 추출, 커밋 메시지 생성, PR 설명 생성 등 핵심 기능의 정상 동작을 확인하였다.

프롬프트 비교 실험을 통해 구체적인 제약 조건과 Few-shot 예시를 제공하면 출력 형식 및 변경 유형 판단을 개선할 수 있음을 관찰하였다.

추가적으로 다음 기능을 구현하였다.

- Git diff 길이 제한
- Conventional Commits 출력 형식 검증
- PR 필수 항목 검증
- HTTP 상태 코드별 오류 처리
- API 응답 시간 제한
- 토큰 사용량 출력

추가된 기능은 최종 버전에서 별도의 테스트를 통해 검증할 필요가 있다.

## 6. 결론

Python CLI 프로그램에서 Git과 외부 AI API를 연동하여 커밋 메시지와 PR 설명을 생성하는 핵심 기능을 구현하고 정상 동작을 확인하였다.

또한 프롬프트 설계에 따른 결과물 품질과 토큰 사용량의 차이를 확인하였다.

AI가 생성한 결과는 항상 정확하지 않을 수 있으므로 출력 형식 검증과 개발자의 최종 검토가 필요하다.
